# Patient Portal

The Cloud Care Pharmacy Patient Portal — a web app for managing patients, prescriptions, consultations, and day-to-day clinic operations.

## What it does

- Manage patient records and intake
- View and track prescriptions
- Schedule and review consultations
- Coordinate tasks and rosters across the team
- Automate clinic processes with workflows and message templates

Product catalog, customer orders and stocktakes live in the sibling [FastMedOps](https://github.com/Cloud-Care-Pharmacy/fastmeds-ops) operations platform, which shares this app's design system, auth and backend.

## Who it's for

Cloud Care Pharmacy staff, doctors, and administrators.
